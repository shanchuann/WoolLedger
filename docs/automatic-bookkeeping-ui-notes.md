# 自动记账页面交互选型

沿用现有纸色背景、圆角描边纸卡、圆形返回键和 ThemePopup，不引入另一套视觉主题。

| 场景 | 候选与判断 | 实现 |
| --- | --- | --- |
| 入账方式 | 点击轮换不便预知下一状态；只有两个固定选项，适合单选菜单 | 复用 ThemePopup，标出当前项，选择后生效，返回或点击外侧取消 |
| 支付应用 | 多个来源可同时启用，不适合单选菜单；需要补充银行包名 | 自定义多选弹窗，取消放弃修改，保存前校验包名 |
| 开启与撤销 | 涉及通知读取授权或账目删除，需要明确确认 | 主题自定义确认弹窗，提供取消和明确的操作按钮 |
| 核对账目 | 多字段任务不适合零散系统输入框或整页跳转 | 自定义表单弹窗，内容可滚动、操作栏固定，错误保留输入，确认成功才关闭 |

列表使用待确认/处理记录分段切换，通知原文按需打开，缺失金额显示待补全。浅深色均从 ThemeUtil 取色，系统通知授权仍使用 Android 必需的系统设置页。
